### 01. FormMate AI
- Category: AI productivity
- Subtitle: Controlled AI form completion
- Description: An AI-assisted form companion for completing tedious web forms with reviewable voice or text guidance.
- Long description: FormMate AI turns a form URL and a short conversational intake into editable draft responses. Automation stops before submission, leaving the user to review, correct, and decide what gets used.
- Current status: Review-first product workflow defined in the repository.
- Tags: typescript, ai, voice, automation
- Tools used: TypeScript, Next.js, React, Vercel, AI-assisted workflows, Voice/text intake, Prompt design, Form parsing, Review-first UX, Validation flows, Browser automation patterns, Accessible form states
- Product focus / What it does: A review-first form copilot for moving through long applications without surrendering the final decision.
- Problem / What it solves: Re-entering the same context across lengthy forms is slow and error-prone; one missed field can undo an otherwise strong application.
- Solution / How it works: Collect context once, generate editable field-level drafts, and keep submission outside the automation boundary.
- Developer notes / My read on it: This is a place where AI can remove tedious work without pretending it should take responsibility. The core product question is how far automation can go before trust, accuracy, and user intent are compromised.
- GitHub: https://github.com/iice257/FormMate
- Website: https://form-mate-ai.vercel.app
